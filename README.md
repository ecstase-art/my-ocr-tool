# my-ocr-tool
📄 MinerU OCR – Пакетная обработка документов
Графический инструмент для массового распознавания текста (OCR) с использованием облачного API MinerU.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)

📌 Описание
Это приложение позволяет пакетно обрабатывать PDF, изображения и офисные документы (Word, Excel, PowerPoint) через API MinerU.
Программа автоматически распознаёт текст (включая сканы и фотографии), сохраняет результат в HTML с сохранением структуры (таблицы, заголовки, форматирование) и исправляет ориентацию перевёрнутых изображений.

Ключевые особенности:

Поддержка множества форматов: PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX, PNG, JPG, JPEG, JP2, WEBP, GIF, BMP.

Автоматическое исправление ориентации изображений (90°, 180°, 270°) через Tesseract.

Копирование оригиналов офисных файлов в папку с результатами.

Возобновление работы после прерывания (сохранение прогресса в processed.json).

Графический интерфейс с прогресс-баром и логом действий.

Пакетная загрузка до 50 файлов за раз (с возможностью настройки).

🚀 Установка и запуск
📦 Для пользователей (готовый EXE)
Скачайте последнюю версию ocr.exe из раздела Releases.

Установите Tesseract OCR (для автоматического поворота изображений):

Скачайте установщик с официального сайта.

Во время установки обязательно отметьте язык Russian (и другие нужные).

После установки перезапустите компьютер или добавьте путь к Tesseract в переменную PATH.

Запустите ocr.exe — никаких дополнительных установок не требуется.

🐍 Для разработчиков (из исходников)
Убедитесь, что установлен Python 3.10 или выше.

Установите зависимости:

bash
pip install -r requirements.txt
Запустите скрипт:

bash
python ocr_gui.py
Для сборки EXE:

bash
pyinstaller --onefile --windowed --name="ocr" --hidden-import=cv2 --hidden-import=pytesseract ocr_gui.py
🖥️ Как пользоваться
Выберите папку с документами (нажмите «Обзор…»).

Введите название проекта — в этой папке появятся результаты.

Нажмите «Запустить обработку».

Следите за прогрессом в окне программы.

После завершения нажмите «Открыть папку», чтобы увидеть результаты.

⚙️ Технические детали
API: MinerU (облачный, бесплатно до 2000 страниц в день при наличии ключа).

OCR: Tesseract (локально, для коррекции ориентации).

Форматы на входе: PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX, PNG, JPG, JPEG, JP2, WEBP, GIF, BMP.

Формат на выходе: HTML (сохраняет структуру, таблицы, заголовки).

Автоматическая коррекция: поворот изображений на 90°, 180°, 270° через Tesseract (если Tesseract не установлен, коррекция пропускается).

Пакетная обработка: до 50 файлов за один запрос (можно изменить в коде).

Возобновление: при повторном запуске программа пропускает уже обработанные файлы (используется processed.json).

📦 Зависимости
Для разработки потребуются:

opencv-python — обработка изображений

pytesseract — определение ориентации текста

Pillow — работа с изображениями

requests — HTTP-запросы к API

markdown — конвертация Markdown в HTML

pyinstaller — сборка EXE
